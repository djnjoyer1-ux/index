# Arcana Frontier: Runehold

A self-contained first-person pixel-fantasy roguelike made with HTML5 Canvas and vanilla JavaScript.

## Run
Open `index.html` in a modern browser. Click the game to capture the mouse.

## Controls
- WASD: move
- Mouse or arrow keys: look
- Left click or Space: cast
- 1-4: select spell
- Shift: sprint
- M: toggle map

No installation, server, or external assets are required.
